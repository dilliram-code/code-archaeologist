# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.19.x (Modern Revival) | :white_check_mark: Supported |
| < 0.19.0 | :x: Unsupported / End-of-Life |

## Reporting a Vulnerability

If you discover a security vulnerability in Eel, please report it responsibly.

- Do **not** open a public issue on GitHub.
- Submit a private security advisory through GitHub Security Advisories or contact the maintainers directly.
- Include a minimal reproducible example, affected operating system, Python version, and detailed description of the potential impact.

The maintainers will review the report, develop a fix in private, and issue a patched release.
